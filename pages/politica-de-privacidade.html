Política de Privacidade

Esta política descreve o tratamento de dados no serviço Currículos 1R$.

Dados inseridos no currículo

Os dados preenchidos no editor são armazenados localmente no navegador por meio de localStorage para permitir a continuidade do rascunho. O servidor não precisa receber o conteúdo completo do currículo para gerar a prévia ou a impressão.

Dados de pagamento

Para criar uma cobrança PIX, o serviço envia ao Mercado Pago os dados necessários à operação, como e-mail, nome e, quando informado, CPF. O processamento financeiro é realizado pelo Mercado Pago.

Finalidades

  • Manter o rascunho no dispositivo.
  • Criar e confirmar a cobrança.
  • Liberar o download após a confirmação.
  • Prevenir abuso e manter a segurança.

Seus controles

O botão Reiniciar remove o rascunho salvo no navegador. Também é possível limpar os dados do site nas configurações do navegador.

Contato

Solicitações relacionadas à privacidade podem ser enviadas pela página de contato.
