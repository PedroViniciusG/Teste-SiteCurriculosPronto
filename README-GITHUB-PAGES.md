# Versão de teste — GitHub Pages

Esta edição é totalmente estática e usa pagamento simulado. Nenhum valor é cobrado.

## Publicar
1. Envie o conteúdo desta pasta para a raiz do repositório.
2. Em Settings > Pages, escolha Deploy from a branch.
3. Selecione main e / (root).

O arquivo index.html deve permanecer na raiz.

## Recursos experimentais desta versão

- Cidade e estado separados, com seleção de UF.
- Reordenação de experiências e formações por arrastar ou pelas setas.
- Agrupamento automático de cargos na mesma empresa na prévia.
- Classificação do tipo de formação acadêmica.
- Informações adicionais exibidas com o título correto.
- Saída após o pagamento simulado por impressão ou download direto em PDF.

O download direto utiliza bibliotecas carregadas pelo jsDelivr. Caso elas não carreguem, a opção **Imprimir currículo** permanece disponível.
