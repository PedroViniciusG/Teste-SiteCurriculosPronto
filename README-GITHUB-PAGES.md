# Versão de teste — GitHub Pages

Esta edição é totalmente estática e usa pagamento simulado. Nenhum valor é cobrado.

## Publicar
1. Envie o conteúdo desta pasta para a raiz do repositório.
2. Em Settings > Pages, escolha Deploy from a branch.
3. Selecione main e / (root).

O arquivo index.html deve permanecer na raiz.
